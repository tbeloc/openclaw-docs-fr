# Fournisseurs hébergés long-tail - Note de maturité des fournisseurs LLM hébergés

## Résumé

Les adaptateurs de texte hébergés compatibles avec OpenAI sont en Beta pour la couverture et en Alpha pour la qualité. De nombreux fournisseurs disposent de manifestes, de catalogues, de métadonnées de requête, de couverture unitaire et de tests en direct ciblés, mais le raisonnement spécifique au fournisseur, les appels d'outils, la recherche, le streaming et le comportement du catalogue de modèles maintiennent le score de qualité en dessous de Beta.

## Score de couverture

- Score : `Beta (74%)`
- Signaux positifs :
  - Des manifestes de fournisseurs existent pour de nombreux fournisseurs de texte hébergés compatibles avec OpenAI, notamment DeepSeek, Groq, Mistral, Together, xAI, DeepInfra, Fireworks, Cerebras, NVIDIA, Hugging Face, Chutes, Venice, Arcee, Kilo, OpenCode et OpenCode Go.
  - Des tests en direct existent pour les chemins DeepSeek, Together, xAI et OpenCode.
  - `docs/help/testing-live.md` recommande DeepSeek et xAI/Mistral/Cerebras optionnels dans les ensembles de smoke de modèles.
  - Les tests unitaires/contrats couvrent la politique du fournisseur, la mise en forme des requêtes du fournisseur, le streaming, les ID de modèles, la recherche web, les adjoints de compréhension des médias et l'enregistrement des plugins pour plusieurs adaptateurs.
- Signaux négatifs :
  - La preuve en direct est inégale dans toute la famille de fournisseurs.
  - L'itinéraire n'est que nominalement compatible avec OpenAI pour de nombreux fournisseurs ; le raisonnement, l'outil, l'ID de modèle, le préfixe et le comportement de recherche divergent toujours.
  - Certains fournisseurs s'appuient fortement sur des catalogues statiques ou des récupérations de catalogues à l'exécution plutôt que sur une voie en direct récurrente uniforme.

## Score de qualité

- Score : `Alpha (68%)`
- Bonnes qualités :
  - Les manifestes appartenant aux fournisseurs maintiennent les choix d'authentification, les métadonnées de requête du fournisseur, les catalogues de modèles, les descripteurs de configuration et les contrats de capacité proches du plugin.
  - DeepSeek maintient la résolution du catalogue V4 et le comportement de relecture de la réflexion proches de l'adaptateur du fournisseur.
  - Together maintient les métadonnées du modèle de catalogue et la mise en forme de complétion compatible avec OpenAI dans le code appartenant au fournisseur.
  - Les documents du fournisseur appellent explicitement les bizarreries de compatibilité telles que le comportement des réponses xAI, la gestion du raisonnement proxy Kilo, les préfixes imbriqués NVIDIA et le comportement de l'URL de base Cerebras.
- Mauvaises qualités :
  - L'étiquette partagée compatible avec OpenAI cache des différences significatives spécifiques au fournisseur dans le raisonnement, le streaming, la relecture des appels d'outils, les ID de modèles et les wrappers de sécurité.
  - Les preuves d'archive montrent un churn large multi-fournisseur de clé API et de catalogue de modèles.
  - Les fournisseurs long-tail peuvent modifier la disponibilité et la compatibilité des modèles sans modifications de source OpenClaw.
- Exclus de la qualité :
  - Les preuves unitaires, d'intégration et en direct ont été utilisées uniquement pour le score de couverture.
