# Inventaire des plugins

Cette page est générée à partir de `extensions/*/package.json`, `openclaw.plugin.json`,
et les exclusions `files` du package npm racine. Régénérez-la avec :

```bash
pnpm plugins:inventory:gen
```

## Définitions

- **Package npm principal :** intégré au package npm `openclaw` et disponible sans installation de plugin séparé.
- **Package externe officiel :** plugin maintenu par OpenClaw omis du package npm principal, conservé dans cet inventaire officiel, et installé à la demande via ClawHub et/ou npm.
- **Source locale uniquement :** plugin local au dépôt omis des artefacts npm publiés et non annoncé comme package installable.

Les sources locales sont différentes des installations npm : après `pnpm install`, les plugins fournis se chargent à partir de `extensions/<id>` afin que les modifications locales et les dépendances d'espace de travail spécifiques au package soient disponibles.

## Installer un plugin

Utilisez la colonne **Distribution** pour décider si une installation est nécessaire. Les plugins qui indiquent `inclus dans OpenClaw` sont déjà présents dans le package principal. Les packages externes officiels nécessitent une installation, puis un redémarrage de Gateway.

Par exemple, Discord est un package externe officiel :

```bash
openclaw plugins install @openclaw/discord
openclaw gateway restart
openclaw plugins inspect discord --runtime --json
```

Pendant la transition de lancement, les spécifications de package ordinaires s'installent toujours à partir de npm.
Utilisez `clawhub:@openclaw/discord` ou `npm:@openclaw/discord` lorsque vous avez besoin d'une source explicite. Après l'installation, suivez la documentation de configuration du plugin, comme [Discord](/fr/channels/discord), pour ajouter les identifiants et la configuration du canal. Consultez [Gérer les plugins](/fr/plugins/manage-plugins) pour les commandes de mise à jour, désinstallation et publication.
