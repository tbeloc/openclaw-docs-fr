# Plugin File Transfer

Récupérez, listez et écrivez des fichiers sur des nœuds appairés via des commandes de nœud dédiées. Contourne la troncature stdout bash en utilisant base64 sur node.invoke pour les binaires jusqu'à 16 MB.

## Distribution

- Package: `@openclaw/file-transfer`
- Install route: included in OpenClaw
