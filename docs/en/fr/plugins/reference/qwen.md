# Plugin Qwen

Ajoute la prise en charge du fournisseur de modèles Qwen, Qwen Cloud, Model Studio, DashScope à OpenClaw.

## Distribution

- Package : `@openclaw/qwen-provider`
- Route d'installation : incluse dans OpenClaw

## Surface

providers: qwen, qwencloud, modelstudio, dashscope; contracts: mediaUnderstandingProviders, videoGenerationProviders
