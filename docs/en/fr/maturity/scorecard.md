# Fiche de maturité

Ces scores résument la préparation à la sortie dans les domaines de produits OpenClaw, les intégrations et les flux de travail pris en charge.

La fiche actuelle couvre 50 surfaces et 281 domaines de capacité.

## Scores globaux

| Base             | Couverture          | Qualité        | Complétude   |
| ---------------- | ------------------- | --------------- | ------------ |
| Moyenne surface  | `Expérimental (1%)` | `Alpha (63%)`  | `Bêta (70%)` |
| Moyenne catégorie | `Expérimental (1%)` | `Alpha (64%)`  | `Bêta (71%)` |

- La couverture est dérivée des preuves du profil QA.
- La qualité mesure la fiabilité et la confiance opérationnelle.
- La complétude mesure la part du flux de travail utilisateur attendu qui est disponible.

## Bandes de score

| Étiquette      | Plage de score |
| -------------- | -------------- |
| Attachant      | 95-100%        |
| Stable         | 80-95%         |
| Bêta           | 70-80%         |
| Alpha          | 50-70%         |
| Expérimental   | 0-50%          |
