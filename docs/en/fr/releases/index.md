# Notes de version

Ces pages seront la version destinée aux lecteurs des versions d'OpenClaw. Elles conservent
l'histoire principale, l'impact pratique, les liens sources et le crédit des contributeurs ensemble
sans vous obliger à scanner d'abord le journal des modifications brut.

## À venir

L'archive des versions est en cours de remplissage rétroactif. De nouvelles notes de version polies apparaîtront
ici après la finalisation de la copie de version.

## Historique des versions brutes

Utilisez les notes curées quand vous voulez l'histoire du produit. Utilisez l'historique brut quand
vous avez besoin d'une comptabilité compacte des mainteneurs :

- [GitHub releases](https://github.com/openclaw/openclaw/releases)
- [CHANGELOG.md](https://github.com/openclaw/openclaw/blob/main/CHANGELOG.md)
